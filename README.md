# MyWallet

Aplikasi pelacak keuangan pribadi modern dan *offline-first* yang dibangun menggunakan **React Native**, **Expo SDK 58**, **TypeScript**, dan **SQLite**.

### Fitur Utama
- **100% Offline & Aman**: Seluruh data transaksi tersimpan lokal di perangkat menggunakan SQLite.
- **Rekap Multi-Periode**: Filter dan ringkasan transaksi per Hari, Minggu, Bulan, dan Tahun dengan kalkulasi saldo akhir otomatis.
- **Pengingat Tagihan & Notifikasi**: Pemilih tanggal & jam interaktif dengan jadwal alarm notifikasi lokal.
- **Multi-Dompet / Akun**: Kelola rekening bank, tunai, dan e-wallet dengan kustomisasi warna dan ikon.
- **Haptic Feedback**: Pengalaman interaksi taktil yang responsif dan mulus.
- **Onboarding Cepat**: Input nama pengguna pada saat instalasi pertama.

### Tech Stack
- **Framework:** React Native (Expo SDK 58)
- **Language:** TypeScript
- **Database:** SQLite (`expo-sqlite`)
- **Notifications:** `expo-notifications`
- **Haptics:** `expo-haptics`
- **Icons:** `@expo/vector-icons` (Ionicons)

### Cara Menjalankan Project
```bash
# Install dependencies
npm install

# Start development server
npx expo start
```
